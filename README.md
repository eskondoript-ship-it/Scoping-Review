# Scoping Review: Hybrid Intelligence & Human-AI Collaboration

![License](https://img.shields.io/badge/license-Apache--2.0-blue.svg)

## Overview

This repository contains the dataset, references, and supporting materials for a scoping review focused on:

* Hybrid Intelligence (HI)
* Human-in-the-Loop (HITL) systems
* Human–AI collaboration
* Human-centered AI decision support
* AI oversight and governance
* Human supervision in autonomous and semi-autonomous systems

The primary objective of this repository is to organize and analyze academic literature related to collaborative intelligence systems and the interaction between humans and AI agents across multiple domains.

## Dataset Description

The main dataset is contained in:

* `Reviewed Papers EsKondori.xlsx`

### Included Metadata

Each reviewed paper may contain:

| Field                | Description                              |
| -------------------- | ---------------------------------------- |
| Paper ID             | Unique identifier                        |
| Full Title           | Complete publication title               |
| Authors              | Paper authors                            |
| Year                 | Publication year                         |
| Publication / Source | Journal, conference, or repository       |
| Methodology          | Research methodology or approach         |
| Limitations / Gaps   | Identified limitations and research gaps |
